How to sideload (first-time setup)
  1. Run PAE Bird. Open the PAE Bird Mac app and leave it running — the Excel add-in talks to it locally, so it needs to be open in the background whenever you use PAE formulas.
  2. Download manifest.xml above. (If it opens as text in a new tab instead of downloading, use your browser's Save Page As / Ctrl+S to save it as manifest.xml.)
  3. On Mac: open Finder, press Cmd+Shift+G, and go to:
    ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef
    (create the wef folder if it doesn't already exist), then copy manifest.xml into it.
  4. On Windows, or Excel on the web: in Excel, go to Home → Add-ins → More Settings, choose Upload My Add-in on the Office Add-ins dialog, then browse to and select manifest.xml.
  5. Open (or restart) Excel and open any workbook.
  6. On Mac, go to Home → Add-ins and select PAE Bird from the menu that appears.
  7. The PAE Bird button/task pane appears, and formulas like =PAE.SOLVE(...) work in any cell.

Official Microsoft instructions: Mac · Windows / web

Download not working? Copy manifest.xml directly

If the download button isn't cooperating (some security software blocks files named "manifest.xml"), copy the text below into a new file on your computer named exactly manifest.xml, then continue from step 3 above.

=PAE.SOLVE("x^2 - 5x + 6 = 0") =PAE.EXPAND("(2x-1)^3") =PAE.FACTOR("2x^2 + 6x + 4") =PAE.DIFFERENTIATE("x^3 + 2x","x") =PAE.INTEGRATE("3x^2","x")

All five PAE functions returning results live in Excel cells.

Native Excel formula syntax — type it just like any other function.

About Stewart Breier

Work on PAE Bird began with hand coding, with the first few rounds in LISP, before migrating to C++, and now to Chez Scheme. Later developments increasingly incorporated AI. The first spark of a dream of a PAE Bird originated during my youthful programming lessons in BASIC, where I was amazed at how I could automate Algebra.

When I am not programming PAE Bird, I am in the classroom as a Substitute Teacher, furthering my education at National University in their MSW program, submitting my poetry, playing TTRPGs, painting digital art, or working on my Tai Chi.
